# Gaddi Language Archive (Sal Valley Dialect)

This is a documentation project for the **Sal Valley dialect of Gaddi**, a Western Pahadi language. 

**This is not an academic linguistic project.** This is a grassroots archive created entirely by a **native speaker** to preserve our language accurately.

## 🌐 Permanent Record
* **Zenodo DOI:** https://doi.org/10.5281/zenodo.23831916
