# Gaddi Minimal or Near-Minimal Pairs

| Pair | Gaddi | English |
| :--- | :--- | :--- |
| **1** | baNai | make |
| | bhanAi | break |
| | banhAi | tie |
| **2** | pAr | across |
| | PAr | comb |
| **3** | bAr | day |
| | BAr | outside |
| **4** | hing | horns |
| | Hing | sniff |
| **5** | ghA | injury |
| | GhA | grass |
| **6** | sanjh | evening |
| | sanj: | prasAd/offering(to deity) |
| **7** | helki | little (feminine) |
| | heLki: | rabid |
| **8** | nAErA~ | in canal |
| | nhaerA | darkness |
| **9** | baN | forest |
| | Bann | tie |
| | bhan: | break | 
| **10** | mei~yae | solely by me |
| | mhei~yae | by the buffalo |
| **11** | dassA | tell me |
| | das^hA | show me |

## examples

| | Gaddi | English |
| :--- | :--- | :--- |
| 1. | e kas thau~ baNau | from whom did you get it made? |
| | e kao bhanau | why did you get it broken? |
| | e kas thau~ banhau | from whom did you get this tied? |
| 2. | I~dae ghar: pAr hinnae | our house is across (the hill) |
| | haerao PAr apNae | comb your hair | 
| 3. | aj: kuN bAr ha? | what day is it today? |
| | BAr aye | come outside |
| 4. | esiyo Hing | sniff this |
| | gaI rae kituNae hing bhu~dae | how many horn does a cow have |
| 5. | gOruo GhA paI deya | give fodder to the cattle |
| | e ghA kiyA~ bhuA | how did you get this injury |
| 6. | sanj bhuci gayi | it has become evening  |
| | sanj: baNi gyi | is the offering ready? |
| 7. | tundI helki kuLi ra kae nA~ ha | what is the name of your younger daughter |
| | taeRi ak kuttar heLkI gacchUrA | a dog has gone rabid over there |
| 8. | nAerA ra paNi kIyA~ huki go | how did the water in the canal dry up |
| | nhaerA bhuci gachUrA | it has become dark |
| 9. | baNA~ baN patALi bhundi | there are forest spirits in the forest |
| | sUtar bann bhalA racchA puri | tie the strings on the loom |
| | e bhan-kuNALi kuNi lauri karna | who is causing this ruckus |
| 10. | bas har tAEm mei~yae karu, mei~yae karu karda rendA | you keep on saying "i did it" every time. |
| | mhei~yae ghA khai leu | the grass was eaten by the buffalo |
| 11. | munju dassA kae bhua | tell me(formal), what happened? |
| | munju das^hA kae bhua | show me what happened |
