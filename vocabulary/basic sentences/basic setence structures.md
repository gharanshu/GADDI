## BASIC SENTENCES in GADDI - SAL Dialect 

| sentence | meaning | notes |
| :--- | :--- | :--- |
| rAm pANiâ pindâ | ram is drinking water | ram water-is-ing drinks, pANiâ - pANi + hâ |
| rAm anshuo pANiâ piandâ | ram is making anshu drink water | ram anshu-to water-is-ing make-drink |
| rAmmæ anshuo pANi piau | ram made anshu drink water | (hindi : ram ne) anshu-to water make-to-drank |
| inmae gàNâ | we will go via this road | normal |
| innimae gàNâ | we will go via this very road | emphasis |
| inniεmae gàNâ | we will go through this very road | emphasis + transitive |
| esmae hâ | he has it | |
| essæmae bhUNâ | he's prolly the one who has it | |
